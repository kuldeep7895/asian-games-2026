# 🇮🇳 Asian Games 2026 Schedule & Results Tracker

Real-time schedule, match timings, and results tracker for the **Indian Contingent** at the **20th Asian Games (Aichi-Nagoya 2026)**.

## 🌟 Features

* **🇮🇳 Team India Focused:** Pre-filtered to Indian fixtures across Cricket, Hockey, Badminton, Table Tennis, Kabaddi, Shooting, Boxing, Athletics, Squash, and more.
* **🕒 Dual Clocks & Chronological Order:** Every match is sorted by start time and displayed in **IST (India Standard Time)** and **JST (Japan Standard Time)**.
* **🔴 Live 30s Auto-Sync:** Real-time in-browser polling every 30 seconds for live score and schedule updates.
* **🏆 Medal Highlights:** Instant breakdown of India's medals, event details, and winning squad members.
* **⚡ 5-Minute Cloud Sync:** Automated GitHub Actions workflow syncing directly with the official Bornan sports backend.
* **📦 JSON Data Exporter:** One-click download or inspection of clean, decompressed schedule JSON feeds.
